# Long-term Thermal Effects of Functional-Ecological Land Transitions in Shenzhen

Code and data for: **"Long-term thermal effects of functional-ecological land transitions in Shenzhen, 2000–2020"**

Ke Zhu, Hongwei Lu\*, Tianci Yao, Xiaohan Zhang, Dongzhe Liang, Peipei Tian


## Overview

This repository contains the notebook, scripts, and a compact data package used to reproduce the Shenzhen functional-ecological land-use reconstruction and thermal analysis workflow. The study fuses multi-source labels (POI, EULUC, TCULU) with Landsat time-series features on a 200 m hexagonal grid to classify five functional-ecological land use types—production land, living land, green space, water bodies, and farmland—across Shenzhen from 2000 to 2020. It then quantifies the static land surface temperature (LST) differentiation across functional types and the dynamic, stage-dependent thermal effects of land use transitions using propensity score matching (PSM).

## Setup

### 1. Clone this repository

```bash
git clone https://github.com/kzhu3118/shenzhen-functional.git
cd shenzhen-functional
```

### 2. Create environment

```bash
pip install -r requirements.txt
```

A geospatial Python environment is required (GeoPandas, rasterio, scikit-learn, and related packages).

### 3. Run the notebook

Open `UFS_2020_v2.ipynb` from the repository root and execute the cells in order. All project paths in the copied scripts have been rewritten to use repository-relative paths.

Some cells submit Google Earth Engine (GEE) export tasks, which require Earth Engine authentication and the grid asset configured in the corresponding scripts. To inspect downstream code without running GEE, use the included CSV feature tables in `data/GEE/shenzhen_features_2000_2020/`.

## Data Policy

To stay within standard GitHub file limits, this repository provides a compact data package rather than the full raw collection:

- **POI data**: Only the first 50 records from each raw POI shapefile are included under `data/poi_2020/`, intended for checking schema, code execution, and preprocessing logic. The full cleaned POI GeoPackage exceeds the single-file limit and can be regenerated from the sampled files (for code checks) or from the full raw POI collection.
- **Model artifacts**: Large Random Forest (RF) `.joblib` files are not included and can be regenerated by running the training scripts. The model-validation plotting script skips RF variable-importance calculation when the RF artifact is absent, while retaining the tabular performance summaries already included.
- **TCULU rasters**: The raw national TCULU rasters are not included; the extracted Shenzhen clips and validation products are provided under `data/tculu_shenzhen/`. To rerun extraction, place `china_land_useYYYY.tif` files under `data/external/china_urban_landuse/`.

## Data Sources

| Dataset | Source | Resolution |
|---|---|---|
| Points of Interest (POI) | [Amap (Gaode)](https://lbs.amap.com/) | Point |
| Essential Urban Land Use Categories (EULUC) | Gong et al. (2020) | Parcel |
| Time-Consistent Urban Land Use (TCULU) | Xiong et al. (2026) | 30 m |
| Landsat 5/8 Surface Reflectance | [USGS](https://www.usgs.gov/landsat-missions) | 30 m |
| MODIS Land Surface Temperature (MOD11A2) | [NASA LP DAAC](https://lpdaac.usgs.gov/) | 1 km |
| Nighttime Light (DMSP-OLS / NPP-VIIRS) | Harmonized NTL product | ~500 m–1 km |
| Global Artificial Impervious Area (GAIA) | Gong et al. (2020) | 30 m |
| Digital Elevation Model (NASADEM) | [NASA](https://www.earthdata.nasa.gov/) | 30 m |
| Administrative boundaries | National Geomatics Center of China | Polygon |
